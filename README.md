# 🎬 Movie Recommendation System

A simple and interactive Movie Recommendation System built using Python that helps users discover movies based on popularity and genres.

Users can explore popular movies, browse movies by genre, and search for specific movie titles. Each movie provides a short overview and its rating to help users choose what to watch.

## ✨ Features

- 🔥 **Popular Movies:** Explore popular movies.
- 🎭 **Genre-Based Browsing:** Discover movies based on different genres.
- 🔍 **Movie Search:** Search for movies by their titles.
- 📝 **Movie Overview:** Read a short summary of each movie.
- ⭐ **Movie Ratings:** View movie ratings before deciding what to watch.

## 🛠️ Technologies Used

- Python
-API Keys
-Streamlit

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Gurleen3178/Movie-recommendation-system.git
```

### 2. Navigate to the project folder

```bash
cd Movie-recommendation-system
```

### 3. Install dependencies


```bash
pip install -r requirements.txt
```

### 4. Run the application



```bash
python app.py
```



## 🎯 Project Objective

The goal of this project is to make movie discovery easier and more enjoyable by providing users with popular movies, genre-based browsing, movie search functionality, summaries, and ratings.
